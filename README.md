# vittara clinic

Claro — aqui está um prompt bem completo para você colar no Lovable e gerar uma landing page elegante para a Vittara Estética Avançada:

Crie uma landing page moderna, elegante, feminina e sofisticada para a clínica Vittara Estética Avançada.

A página deve transmitir estética premium, beleza natural, confiança, ciência, cuidado personalizado e resultados harmônicos. O visual deve seguir uma linguagem parecida com artes editoriais de clínicas de estética de alto padrão, com leitura leve, respiro visual e muito refinamento.

IDENTIDADE VISUAL:

Use uma estética clean, clara e sofisticada, inspirada em beleza premium, skincare coreano, estética avançada e atendimento personalizado.

Paleta de cores:

Rosa claro/nude como cor principal

Off-white e bege claro para fundos

Marrom rosado para textos e detalhes

Rosé/cobre suave para destaques

Branco para áreas de respiro

Dourado muito sutil apenas em pequenos detalhes, linhas finas ou ícones delicados

Tipografia:

Usar Playfair Display para títulos principais, com elegância editorial.

Usar Poppins para textos, botões, menus e descrições.

Títulos grandes, com bastante presença.

Textos bem espaçados, fáceis de ler e com hierarquia clara.

Estilo visual:

Fundo claro com textura suave, como papel premium ou gradiente nude.

Elementos florais delicados, pétalas, linhas orgânicas finas, formas arredondadas e transparências suaves.

Imagens de mulheres com pele glow, expressão natural, estética elegante e realista.

Evitar aparência artificial, excesso de brilho, estética genérica ou poluída.

O layout deve parecer de uma clínica premium, acolhedora e tecnológica.

OBJETIVO DA LANDING PAGE:

Criar uma página de conversão para apresentar a Vittara, seus diferenciais e principais tratamentos, levando a visitante a agendar uma avaliação.

A página deve ser bonita, fluida, persuasiva e de fácil leitura, com chamadas claras para WhatsApp/agendamento.

DIRETRIZES DE DESIGN:

A página deve ser responsiva para desktop e mobile.

No mobile, priorizar leitura fácil, botões grandes e navegação simples.

Usar animações suaves:

Fade-in delicado nos blocos

Hover elegante nos botões

Transições suaves nos cards

Nada exagerado ou chamativo demais

Botões:

Fundo rosa queimado/rosé

Texto branco

Bordas arredondadas

Efeito hover com leve brilho ou mudança para marrom rosado

Cards:

Fundo branco ou rosa muito claro

Bordas arredondadas

Sombra suave

Ícones lineares delicados

Estilo geral:
Premium, feminino, moderno, leve, confiável e acolhedor.

IMPORTANTE:

Não usar linguagem exagerada como “resultado garantido”, “rejuvenescimento imediato” ou “sem riscos”.

Usar uma comunicação ética, elegante e persuasiva.

A copy deve passar confiança, beleza, ciência e personalização.

A landing page deve ter visual de clínica estética premium, com foco em conversão para agendamento. Logo e referencias em anexo.
